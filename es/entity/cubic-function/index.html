Causas

función cúbica Utilizando el resultado obtenido en c, una función cúbica no es una buena elección para este problema porque si a > 0, los valores de la función tienden a infinito a medida que x aumenta y a menos infinito cuando x disminuye.

effects

Efectos

función cúbica Una función cúbica no es una buena opción para este problema porque su coeficiente principal determina el comportamiento al final, el cual puede no alinearse con el resultado requerido. La dirección de la parábola depende del signo del coeficiente principal, afectando cómo se comporta la función cuando x se acerca a infinito positivo o negativo.
