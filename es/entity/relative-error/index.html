definition

Definición

El error relativo se define como el error absoluto dividido por el valor real de la magnitud. Se utiliza para determinar el error porcentual multiplicando el error relativo por 100. El error relativo se expresa como una fracción o decimal, no como un porcentaje.

mechanism

Mecanismo

Para estimar el error relativo, considere ay. Dado que no conocemos el valor exacto del volumen V, use el radio medido r = 4000 millas para estimar V. Obtenemos V ~ (4}-(4000)°.

examples

Ejemplos

Error relativo Al medir la altura de una escalera como 63 pulgadas cuando la altura real es de 62 pulgadas, el error absoluto es de +1 pulgada y el error relativo es de 0.016, o 1.6%. De manera similar, al medir el ancho de una lámina de cartón como 8.25 pulgadas cuando el ancho real es de 8 pulgadas, el error absoluto es de +0.25 pulgadas y el error relativo es de 0.031, o 3.1%.
