vertical asymptote

수직 점근선은 x = 2에서 발생하며, 분모의 (x + 3) 요소에 해당합니다. 그래프는 점근선 양쪽에서 양의 무한대로 향합니다.

definition

정의

수직 점근선은 x = 2에서 발생하며, 분모의 (x + 3) 요소에 해당합니다. 그래프는 점근선 양쪽에서 양의 무한대로 향합니다.

mechanism

기전

수직 비대칭선 x = -3에 해당하는 분모의 (x + 3)² 인자에 대해, 비대칭선 양쪽에서 그래프는 양의 무한대로 향합니다. 이는 함수 f(x) = 1/x²의 행동과 일치합니다.

effects

영향

각 수직 비대칭선 양쪽의 함수의 행동을 분석하여 인자와 그 지수를 판단해야 합니다. 분자 차수가 분모 차수보다 클 경우 수평 비대칭선이 존재하지 않습니다.
