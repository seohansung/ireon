horizontal line test

[horizontal line test|horizontal line test] The horizontal line test is a method used to determine if a relation is a function.

definition

Definition

horizontal line test The horizontal line test is a method used to determine if a relation is a function. A relation that passes this test satisfies the condition of being a function, where each input corresponds to exactly one output. The test involves sketching the graph of the relation and applying a horizontal line to check for one-to-one correspondence. If the line intersects the graph more than once, the relation is not one-to-one. This test helps distinguish between functions and non-functions based on their graphical representation.
