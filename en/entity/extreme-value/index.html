extreme value

Using derivatives

An extreme value of a function is a maximum or minimum value that the function attains at a specific point within its domain. These values can be either relative, meaning they are the highest or lowest in a local region, or global, meaning they are the highest or lowest over the entire domain of the function. A relative maximum occurs at a point where the function changes from increasing to decreasing, while a relative minimum occurs where the function changes from decreasing to increasing.

Conditions and Properties

Any maximum or minimum, whether relative or global, is referred to as an extreme value of the function.
