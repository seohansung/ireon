common logarithm

[common logarithm|common logarithm] is a logarithm with base 10.

definition

Definition

common logarithm is a logarithm with base 10. It defines the exponent to which 10 must be raised to obtain a positive number.

mechanism

Mechanism

common logarithm The common logarithm evaluates expressions with base 10 terms using a calculator. When an equation includes a term with base 10, it requires the common logarithm for calculation.
