first derivative test

Using derivatives

The first derivative test identifies local maxima and minima by analyzing the sign changes of the first derivative around critical numbers. A function changes from increasing to decreasing at a critical number, indicating a local maximum, while it changes from decreasing to increasing, indicating a local minimum.
